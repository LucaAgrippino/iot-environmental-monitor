# IoT Environmental Monitor: Gateway firmware

STM32L475 (B-L475E-IOT01A). Reads its own sensors, polls the Field Device over Modbus RTU (RS-485), and publishes telemetry, health and alarms to the cloud over MQTT with mutual TLS. Receives OTA updates into two firmware slots with rollback.

This is the API reference of the **public headers** (one page per header and per struct). It is generated by `scripts/gen-doxygen.sh`; the warning log of that script is the REQ-NF-505 check.

## How to find your way

- **Data Structures** (menu above): every struct and interface table (the `i...` vtables), with UML-style diagrams of what each one contains and references.
- **Files**: the headers by folder, with include graphs.
- **Search** (top right): any function, type or macro.
- The modules call each other only through the interface tables (`i...` structs). Start from the interface of the module you want, for example `ihealth_report_t`.
